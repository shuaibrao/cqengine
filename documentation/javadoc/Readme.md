# Historical CQEngine Javadocs

`apidocs/` is the unchanged CQEngine 3.5.0 snapshot retained so historical documentation links remain inspectable.
It is not the API documentation for current CQEngine releases.

Generate current documentation with `./gradlew javadoc` and open `build/docs/javadoc/index.html`, or use the staged
`cqengine-<version>-javadoc.jar`. See [using CQEngine artifacts](../Downloads.md).
