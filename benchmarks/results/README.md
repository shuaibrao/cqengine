# CQEngine benchmark results

Each directory contains deterministic tables and SVGs derived from one complete, validated JMH run. Results are
bound to the measured source, benchmark JAR, JDKs and host characteristics. They are machine-specific evidence, not
universal latency, capacity or allocation guarantees.

## Available baselines
